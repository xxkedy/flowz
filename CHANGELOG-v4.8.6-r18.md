# Flowz v4.8.6 r18 — Whole-session Wrap Quality

## 2026-09-11

- `Wrap up` / `まとめて` now explicitly means a recap of the whole THEME or LIFE TALK session, not only the last few turns.
- The recap keeps useful discoveries and decisions that emerge from real conversation, even when FREE TALK moves beyond the original theme.
- Wrap-up now prioritizes up to three high-frequency reusable phrases/words, up to two meaningful corrections, and a concise CEFR + next-focus note.
- Post-session Japanese reflection is routed to the correct existing Notion source: Coach Rules, Implementation Feedback, project source, Diary, or Memo.
- Writes must be re-fetched and verified before Flowz says they were saved.
- GitHub changes remain explicit-only: ordinary session feedback is recorded first; code is modified only when kedy asks for it.
- Added `flowz-v4.8.6-wrap-quality.js` as the final kedy prompt adapter and regression coverage in `tests/wrap-quality.spec.js`.
