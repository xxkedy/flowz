# Flowz v4.5.1 — 2026-08-14

- TALK PREP no longer pins one TODAY phrase for the whole date.
- TODAY advances after each completed COMMUTE session and avoids the three most recent commute phrases.
- TODAY and REUSE rows can be tapped to switch phrases immediately before starting.
- Removed the static `I feel good.` fallback and retired `I haven\'t decided yet.` from the active commute mission pool.
- REUSE now rotates through real recent commute phrases; if none are suitable, it falls back to a different fresh phrase.
- Duo Sync, XP/history, Feedback Loop, TOEIC, FREE, and Leni behavior are unchanged.
