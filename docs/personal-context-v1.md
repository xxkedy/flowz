- current HQ focus
- actual unfinished/relevant ToDo items
- recent Diary entries
- recent Flowz English logs, phrases, fixes, assessment and level notes

Rules:

- prefer latest state and respect completed/postponed/reply-waiting/blocked items
- never expose kedy private context to Leni
